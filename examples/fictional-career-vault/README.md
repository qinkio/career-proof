# 虚构案例：客服流程改造

这是一个完全虚构的职业资料库，只用于展示Career Proof的输出结构。

两份输入资料位于 `evidence/`：

- 一份虚构简历；
- 一份虚构项目复盘。

整理后得到：

- `projects/PRJ-DEMO-001.md`：项目边界、角色和结果；
- `canonical-claims.csv`：两条经过审核的事实；
- `capability-map.csv`：流程优化与跨部门协作能力；
- `review-queue.csv`：已经完成的审核决策；
- `exports/interview-evidence.json`：提供给面试Skill的最小证据包。

案例中的公司、人物、项目和数字均为虚构，不对应真实个人或企业。
