# 中英文术语 / Chinese-English glossary

| 中文 | English | Meaning |
|---|---|---|
| 职业证据库 | career evidence vault | Private source of truth for career facts |
| 来源索引 | source index | Metadata and permissions, not extracted content |
| 项目证据卡 | project evidence card | One objective, time boundary, role, action, and result chain |
| 规范事实 | canonical claim | One atomic reviewed statement with stable ID |
| 审核队列 | review queue | Proposed facts and decisions awaiting user review |
| 能力映射 | capability map | Interpretation linked back to supporting Claim IDs |
| 个人主导 | owned | Candidate held the relevant decision and execution responsibility |
| 共同负责 | co-owned | Decision rights were shared |
| 参与 | participated | Candidate contributed within a larger effort |
| 支持 | supported | Candidate enabled work without owning the outcome |
| 团队结果 | team result | Outcome cannot be attributed solely to the candidate |
| 待确认 | pending | Evidence, definition, attribution, or approval is incomplete |
| 来源冲突 | conflict | Sources disagree or use incompatible definitions |
| 已撤回 | withdrawn | Reserved historical fact excluded from future use |
| 最小证据包 | scoped evidence bundle | Purpose-bound JSON containing only approved relevant facts |

Keep internal enum values stable in English. Preserve user content in its source language and translate only for a declared downstream task.
